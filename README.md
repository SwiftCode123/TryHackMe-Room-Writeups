## TryHackMe – Hacker Holidays (2026)

<p align="center">
<img width="90%" height="90%" alt="image" src="https://github.com/user-attachments/assets/375edf0d-74c3-4d03-8440-4c02803afe95" />

Hacker Holidays is a free, beginner-friendly cybersecurity event hosted by TryHackMe. Over the course of 14 days, a new challenge room is released daily, beginning on July 27, 2026. The event features hands-on challenges covering OSINT, web exploitation, cloud security, forensics, AI prompt attacks

The challenges are set in The Byte Lotus, a fictional five-star resort with a "zero-star security posture." Participants uncover hidden secrets, investigate suspicious activity, and solve practical cybersecurity challenges through a story-driven experience

Event link: [TryHackMe - Hacker Holidays (2026)](https://tryhackme.com/hackerholidays?utm_source=discord&utm_medium=social&utm_campaign=hackerholidays)
